# 나의 할 일 목록

HTML, CSS, 순수 JavaScript로 만든 간단한 할 일(Todo) 관리 웹 앱입니다.
설치나 빌드 없이 브라우저에서 바로 실행됩니다.

## 주요 기능

- **할 일 추가**: 입력 후 `추가` 버튼을 누르거나 `Enter`를 누릅니다.
- **중복 방지**: 이미 있는 할 일은 등록되지 않습니다. 앞뒤 공백, 연속 공백, 영문 대소문자 차이는 같은 것으로 봅니다.
- **완료 표시**: 체크박스로 완료/미완료를 바꿉니다.
- **수정**: `수정` 버튼을 누른 뒤 `Enter` 또는 `저장`으로 반영하고, `Esc`로 취소합니다.
- **삭제**: 항목별 `삭제` 버튼과, 완료된 항목을 한 번에 지우는 `완료 항목 삭제` 버튼이 있습니다.
- **필터**: 전체, 미완료, 완료 중 하나만 골라 볼 수 있습니다.
- **개수 표시**: 전체 할 일 수와 완료한 할 일 수를 보여줍니다.
- **자동 저장**: 브라우저의 `localStorage`에 저장되어 새로고침해도 목록이 남아 있습니다.

## 실행 방법

1. 저장소를 내려받습니다.
   ```bash
   git clone https://github.com/changhyunkim-del/my-to-do-app.git
   ```
2. `index.html` 파일을 브라우저로 엽니다.

별도의 서버나 패키지 설치는 필요 없습니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 구조 |
| `style.css` | 디자인 |
| `main.js` | 할 일 추가, 수정, 삭제, 필터, 저장 기능 |

## 참고

- 할 일 목록은 사용하는 브라우저에만 저장됩니다. 다른 브라우저나 기기에서는 보이지 않습니다.
- 시크릿 창처럼 저장이 막힌 환경에서도 앱은 동작하지만, 창을 닫으면 목록이 사라집니다.
